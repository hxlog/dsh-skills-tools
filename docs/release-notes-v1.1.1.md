# dsh-skills-tools 1.1.1

1.1.1 是 1.1.0 的修正版，修复界面细节并统一插件标识。

## 修复

- 导入技能、从仓库补齐技能等对话框居中显示，不再贴在屏幕上沿。
- 插件在设置 → 插件列表中的显示名改为「Skills管理器」，简介改为中文，并随系统语言切换；技术包名仍为 `dsh-skills-tools`，不影响安装与升级。
- GitHub 与 npm 的 README 头部 logo 改为插件自身图标（与插件列表一致），替换此前的独立 logo。
- README 截图更新为按仓库分组、展开 SKILL.md、补齐技能与导入对话框的最新界面，并全部脱敏（演示仓库 `acme/*`）。
