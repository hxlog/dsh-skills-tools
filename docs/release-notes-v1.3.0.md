# dsh-skills-tools 1.3.0

1.3.0 在 1.2.0（monorepo 子目录稀疏克隆，此前未单独发布）的基础上，补齐了日常使用最常被问到的三件事：**仓库分组一键折叠**、**上游更新自动检查与提示**、**最近操作弹窗**。

## 新功能

- **全局折叠与默认折叠**
  - 顶部工具区新增「全部展开 / 全部折叠」，一次控制所有仓库分组；每个仓库自己的箭头仍然可用。
  - 首次打开（或新出现的仓库）默认折叠，只显示仓库卡片头；搜索时临时展开命中的仓库，清空搜索后恢复。
  - 折叠状态保存在浏览器 localStorage（`dsh-skills-tools:ui:v1`），刷新页面、重开 DSH 后保持；localStorage 不可用时自动退化为会话内状态，不影响使用。

- **自动检查上游更新**
  - 打开设置页后自动检查一次（距上次检查 ≥ 30 分钟），页面可见时每 30 分钟复查；切到后台不查，恢复可见且已过期时补查。
  - 只检查 Git 来源仓库；本机目录跳过。并发 4、单仓库 20 秒超时，单个仓库失败不影响其它仓库。
  - 检查结果写入 `latestCommit` / `checkedAt` / `lastError`，但**不触发 DSH 重新加载技能**（技能内容没有变化）。
  - 发现新提交时顶部出现横幅：「N 个仓库有新提交 · 全部更新 / 查看 / ×」；× 按仓库与提交签名记住，出现新提交才重新提示。
  - 仓库卡片保留「可更新」角标，并新增仓库级「更新」按钮；技能详情里的「从上游更新」保持不变。

- **全部更新**
  - 横幅上的「全部更新」先弹确认框，再串行调用新增的 `POST /repos/update`，显示「正在更新 2/3…」；单个仓库失败不中断，结束后汇总「已更新 N 个仓库 / N 个仓库更新失败」。

- **最近操作弹窗**
  - 不再在页面底部内联展开，改为工具栏「最近操作」按钮打开的独立弹窗：时间 + 级别圆点 + 消息，最新在最上面。
  - 支持刷新、复制全部记录；有技能名时以代码样式显示。
  - Host 启动时会从 `logs.jsonl` 尾部读回最近 300 条，重启后历史仍然可见（此前只有本次进程内的记录）。

## API 变化

| 接口 | 变化 |
| --- | --- |
| GET /state | 不变 |
| GET /logs | 不变；启动后会包含历史记录 |
| POST /repos/check-updates | 响应新增 `updates` / `failed` / `repos[].updateAvailable` / `repos[].error`；跳过本机目录；失败不再整体报错；不再 invalidate |
| POST /repos/update | **新增**：单仓库更新，返回 snapshot / commit / ref |
| POST /import/commit | 响应新增 `repo`（仓库 id），供导入后自动展开该仓库 |
| 其它接口 | 不变 |

## 内部与兼容

- `lib/util.js` 新增 `mapLimit()`；事件日志支持启动回读。
- `lib/git.js` 的 `remoteHead(source, { timeoutMs })` 支持超时；`git ls-remote` 非零退出时报错而不是静默返回 null（更早暴露凭据/网络问题）。
- 不改变 `state.json` 结构与快照语义；旧 state 直接兼容。
- 默认折叠是行为变化，升级说明里已注明；搜索会临时展开，不影响检索。

## 测试

- `npm test`、`npm run test:manager`、`npm run test:provider`、`npm run ci-check` 全部通过。
- `ci-check` 增加构建新鲜度断言：`client/client.js` 缺少新 i18n 键时直接失败，避免忘记 `node scripts/build-client.mjs`。
- 隔离环境（临时 DSH_HOME + Playwright）实测：
  - 默认全折叠、全部展开、刷新后保持；
  - 搜索自动展开命中仓库；
  - 更新横幅出现、× 关闭并在刷新后保持关闭；
  - 「全部更新」确认框、进度、失败汇总；
  - 最近操作弹窗打开/关闭、记录数量与底栏操作。
